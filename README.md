# 🧠 Artificial Neural Networks (ANN)

This repository contains implementations of Artificial Neural Networks using different frameworks and datasets.

## 🔍 Overview
The goal of this project is to understand how neural networks work across different tools and datasets.

## 📌 Implementations

### 1. ANN using Scikit-learn (Digits Dataset)
- Built a neural network using MLPClassifier
- Applied preprocessing and evaluation

### 2. ANN using TensorFlow/Keras (MNIST Dataset)
- Developed a deep neural network for handwritten digit classification
- Achieved high accuracy through tuning

### 3. ANN using TensorFlow/Keras (Fashion MNIST Dataset)
- Classified fashion images using ANN
- Compared performance with MNIST
